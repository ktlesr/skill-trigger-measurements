# Product marketing context — Meterly

**Product:** Meterly — usage metering and usage-based billing for API companies.
**Audience:** indie developers shipping a paid API (being revisited, see below).
**Replaces:** hand-rolled in-memory counters plus a monthly spreadsheet export to the billing provider.
**Why we win:** metering, rating and invoicing in one SDK call; accurate to the request.
**Voice:** plain, technical, no hype. We never say "revolutionary".
**Proof:** 140 paying customers, 2.1B metered calls per month.
