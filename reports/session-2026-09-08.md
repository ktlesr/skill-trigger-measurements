## Dead ends and mistakes, so they are not repeated

- `$args` is a **reserved** automatic variable in PowerShell. Naming a variable
  that silently empties it.
- PowerShell''s splat operator **eats the leading `@`** of `@ktlsr/assay@0.2.0`,
  so `npx` gets no package name. Do not splat npx arguments; invoke directly.
- The runner needs `CLAUDE_CODE_OAUTH_TOKEN` from `.env`. Without it every
  attempt scores `unknown` with "Not logged in". A 12-attempt smoke caught this
  before the long run — worth doing again.
- `[regex]::Replace` in PowerShell writes `\\b` where the Python source needs
  `\b`. This silently broke a pattern and under-counted a metric. Use plain
  `.Replace()` for regex literals.
- The disclosure metric was under-counted **twice** before the negative list
  read clean by hand. Any text-classification metric needs that audit.
